# C-Cord logo

Single bold mark, no wordmark: a thick rounded letter **C** drawn as a cord. The upper end of the C is a chat speech bubble, the lower end is a cable plug (USB-style connector). White outline so it reads on dark and light panels. Not derived from Discord's logo or wordmark.

## Colours

| Role | Hex |
|------|-----|
| Indigo (C body, bubble ring) | `#3B2FA0` |
| Teal (plug) | `#1FD1C0` |
| White (outline, bubble fill, plug contacts) | `#FFFFFF` |

Background is transparent.

## Files

- `ccord-1024.png` master; `ccord-{512,256,128,64,48,32,24,22,16}.png` are Lanczos downscales of it.
- `ccord-tray-{48,32,24,22}.png` simplified tray variant: heavier strokes, plain plug block without slots, mark confined to the top-left ~80% of the canvas so a count badge can be drawn over the bottom-right corner. The 24 and 22 px tray icons are area-filter downscales of `ccord-tray-48.png` (no Lanczos blur); 22 px adds sharpen 0.4, which keeps the palette and stays inside the bottom-right badge corner.
